# Apogee Engine documentation

The built site of [Apogee Engine](https://github.com/apogeeengine/Apogee.Engine), published at **https://apogeeengine.github.io/docs/**.

This repository holds nothing but the output (the `gh-pages` branch), written by the engine repository's CI. **Do not edit it here:** the sources are in
[`Docs/`](https://github.com/apogeeengine/Apogee.Engine/tree/main/Docs) of the engine repository, next to the code, and pull requests go there.
