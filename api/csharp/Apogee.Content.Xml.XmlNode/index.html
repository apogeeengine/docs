    Class XmlNode¶

    Namespace: Apogee.Content.Xml
    Assembly: Apogee.Content.dll

    An element as content files and schemas are read: its name, its attributes in the order they were written, its children, its text, and the line it starts on. Comments and processing instructions are dropped, a DTD is refused (nothing is loaded from outside the file), and names keep their prefix (xs:element, xsi:type): content is not namespace-aware, so a prefix only has to be declared.
