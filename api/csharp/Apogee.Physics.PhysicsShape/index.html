    Class PhysicsShape¶

    Namespace: Apogee.Physics
    Assembly: Apogee.Physics.dll

    A collision shape: an immutable thing a body (or another shape) is made of, in the body's local space. Made with the static functions, given to , and shared freely: many bodies can use one. Jolt counts references, so a shape that a script lets go of lives on in the bodies that use it.

    public sealed class PhysicsShape : EngineObject

    A grid of heights (terrain): heights is size by size samples row by row (a power of two plus one works best, at least 2), at offset from the origin with the grid spaced by scale in x and z and heights multiplied by its y. A height of at least 1e30 is a hole.
