    Class UiElement¶

    Namespace: Apogee.UI
    Assembly: Apogee.UI.dll

    An element of a document (a div, a text node, a whole document) as scripts hold it. The object is a handle: it names the element without keeping it alive, so one whose element has been destroyed (its document was closed, an ancestor was destroyed) is false and every call on it does nothing or answers "none". An element made with or belongs to the object that holds it until it is put in a tree with or ; an element nobody ever put in a tree is destroyed when the script lets go of it, and one in a tree lives as long as the tree does. Elements are made, moved and changed here.

    public sealed class UiElement : EngineObject
