    Struct Double3¶

    Namespace: Apogee.Core.Numerics
    Assembly: Apogee.Core.dll

    A position in the double-precision world: three doubles (24 bytes). Float has 24 bits of precision, so at 5 km from the origin a float position moves in 0.5 mm steps; a double keeps sub-micrometre steps for thousands of kilometres. Only positions are double. Directions, rotations, scales and everything the GPU sees stay float: positions are turned into float offsets from a nearby origin (the camera) with before they are used. Plain scalar code on purpose: positions are added and subtracted, not crunched in bulk.
