    Class ShaderLibrary¶

    Namespace: Apogee.Rendering.Shaders
    Assembly: Apogee.Rendering.dll

    Where renderers get their shaders. takes the compiled artifact of a shader module when its project was imported (), which is how a shipped game and a mod that ships its shaders work: the Slang compiler is never loaded. A module without an artifact is compiled, as in development, if the compiler is there, and the error says what to do when it is not. The engine's own shaders are mounted as shaders:// (); a mod's are at mod://id/…, with their artifacts in mod://id/imported. The library remembers which files each module it loaded was made from, so that when files change (, from HotReloader.ShadersChanged or a ) it can say which modules are out of date (): rebuilds on that. It is thread safe.
