    Class UiSystem¶

    Namespace: Apogee.UI
    Assembly: Apogee.UI.dll

    The game's user interface: RmlUi with one context (the screen), its documents, fonts and input, behind the script global ui. Documents are written in RML and RCSS (HTML and CSS as RmlUi knows them) with scripts of their own in Luau, or built from Luau; both go through s. RmlUi is process-wide, so there is one system at a time.

    public sealed class UiSystem : EngineObject, IDisposable

    Remarks¶

    Call when the window changes size, once a frame (it lays out and runs animations and delivers nothing by itself: events are delivered when input is given), and let the draw (it is the render overlay: it asks for the picture when the frame's graph is built). Input comes from or from the Mouse, Key and Text calls; each says whether the UI used it, so the game can leave it alone. Without a renderer (headless runs, tests) everything but drawing works. What a document asks to read (its stylesheets, images and fonts) is read through the virtual file system, as res://, mod:// and user:// paths. RmlUi has no stylesheet of its own: ui_base.rcss is put under every document (the document's own rules win), with the default font, Inter.
