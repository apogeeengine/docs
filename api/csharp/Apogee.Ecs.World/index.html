    Class World¶

    Namespace: Apogee.Ecs
    Assembly: Apogee.Ecs.dll

    A Flecs world: entities, components, queries and systems. Components are the unmanaged structs marked [Component] (reflected, so Flecs knows their fields too) or ones a script defined at run time. Not thread safe: use it from one thread.

    MaxLoadEntities¶

    The most entities one load (, ) or one may make, counting the entities of every instance it expands (262,144 by default). A document that would make more is a and nothing is made; the expansion also stops at 64 steps of work for each of them, so a few small files cannot keep a load busy without end however their prefabs nest. Saving a scene expands its instances again, with the same limit.

    Instantiate(string, Entity)¶

    Makes the entities of a prefab file under parent (the world's top level when none) and returns the root, which has ; every entity made has with its id in the file. The entities are plain: the file's components are copied, and changing the instance changes nothing in the file. A prefab inside the prefab is made too, with its own changes (it is an instance in the same way). From a script this reads without the per-mod confinement of fs.read_text, as load_scene_file does.

    public Entity Instantiate(string reference, Entity parent = default)

    Parameters¶

    reference string

    The prefab: a path, uid://… (for the file that has that UID, wherever it moved to) or path|uid://….

    parent Entity

    Where the root goes; none puts it at the top level.

    Entity

    RegisterAssetType(string, Func<uint, AssetRef?>, Func<AssetRef, uint>)¶

    Says how the fields of an asset type (, such as model for ModelRenderer.Model) are saved. Such a field is a number in memory, a handle that only means something in this run (a model's number in the library); a scene holds the it names, the path and the UID, which is what lets it load in another run, and after the file moved.

    public void RegisterAssetType(string type, Func<uint, AssetRef?> toRef, Func<AssetRef, uint> fromRef)

    Parameters¶

    type string

    The asset type, as [Property(Asset = "…")] spells it.

    toRef Func<uint, AssetRef?>

    The reference a handle names, or null when it names nothing that can be saved (a model made in code has no path).

    fromRef Func<AssetRef, uint>

    SavePrefabFile(string, Entity)¶

    Writes root and everything below it as the prefab file at path. The ids in the file stay the same from one save to the next: an entity that came from this file ( of it) keeps its id, and a new one takes the file's nextId and raises it, so an id that was deleted is never used again. The file keeps its UID (a new one gets a new UID). Every entity written is marked as a member of the file, with its id there, so that saving again keeps it. Entity fields that point outside what is saved are left out. An instance of another prefab inside the tree is written as it is in a scene: one element with only what differs from its prefab, numbered in this file. The root itself is written as a plain entity even when it is an instance (a prefab saved from an instance of itself, or of another prefab, holds its entities).

    public void SavePrefabFile(string path, Entity root)

    Parameters¶

    path string

    A path ending in .aprefab, or uid://… for the file that has that UID.

    root Entity

    The one root entity of the file.

    Exceptions¶

    InvalidOperationException

    The world has no , or the tree holds an instance of the prefab being written (the file would contain itself), or what would be written is not a prefab that loads (nothing is written).

    UnauthorizedAccessException

    The path is not in a writable source.

    ArgumentException

    The path does not end in .aprefab, or the entity is not a user entity.

    UniqueName(string, Entity, Entity)¶

    The name, or "name 2", "name 3"… (the first of those that is free) when parent (the top level when none) already has a child of that name other than except: what gives an entity, so that a name is unique among siblings. It looks at the children of that one parent, as Flecs keeps them: not at the whole world, so the entities of the engine (there is one called "Empty") do not count. Names are compared as they are written: "Lamp" and "lamp" are two names.

    public string UniqueName(string name, Entity parent = default, Entity except = default)

    Parameters¶

    name string

    The name wanted. An empty one is no name, and is returned as it is.

    parent Entity

    The parent the entity has or will have; none for the top level.

    except Entity

    The entity that is being named, whose own current name does not count.
