    Class PhysicsWorld¶

    Namespace: Apogee.Physics
    Assembly: Apogee.Physics.dll

    The physics simulation of one ECS : Jolt Physics with double-precision positions, stepped at a fixed rate. Entities get a with ; a dynamic body's entity follows the simulation (its is written, local to its parent, so the world's transform system then fills in the ), and a kinematic body follows its entity.

    public sealed class PhysicsWorld : EngineObject, IDisposable

    Remarks¶

    A frame calls once, before World.Progress, so that the transforms the physics wrote are the ones the frame's systems see and the transform system composes. Everything runs on the thread that calls it (Jolt's workers run inside and never call managed code). A body's ancestors must not be dynamic bodies.
