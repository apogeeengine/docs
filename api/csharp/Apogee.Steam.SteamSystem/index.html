    Class SteamSystem¶

    Namespace: Apogee.Steam
    Assembly: Apogee.Steam.dll

    The game's connection to Steam: the user, the overlay, achievements, stats and leaderboards, rich presence, cloud files and Workshop items. Steam's library is Valve's redistributable and is in the repository; the client is the player's. When Steam is not running, or the game was not started with an app id, is false and every call does nothing and returns something inert, so a game works the same without it.

    public sealed class SteamSystem : EngineObject, IDisposable

    Remarks¶

    Call once a frame: it pumps Steam's callbacks (manual dispatch, all on the calling thread) and turns them into signals. Steam's ids (users, Workshop items) are 64-bit and cross into scripts as decimal strings, because a script number cannot hold them. Mods cannot use this object: it is the game's.
