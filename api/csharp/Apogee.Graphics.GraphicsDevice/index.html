    Class GraphicsDevice¶

    Namespace: Apogee.Graphics
    Assembly: Apogee.Graphics.dll

    The logical device of one graphics API and everything created with it. The renderer talks to this class and the abstract classes it hands out (buffers, images, pipelines, a command recorder, a swapchain and frame loop); Apogee.Graphics.Vulkan has the Vulkan implementation, and a Metal one follows. The engine's baseline is the same on every API: dynamic rendering, explicit barriers, buffer device addresses and bindless textures; a GPU without them is rejected with the reason.
