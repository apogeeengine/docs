    Struct Value¶

    Namespace: Apogee.Reflection
    Assembly: Apogee.Reflection.dll

    A value that crosses between the engine and scripts: no boxing for numbers, vectors, entities and enums. The To… methods check the kind and throw a whose message a script can show.

    public readonly struct Value : IEquatable<Value>
