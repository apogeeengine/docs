    Class ScriptSession¶

    Namespace: Apogee.Host
    Assembly: Apogee.Host.dll

    A script running in a world: the entry script has been executed and its callbacks are registered; the loops step it frame by frame.

    StartGame(string, string?, bool, bool, bool, bool, string?)¶

    Starts a game: folder is res://, userFolder (or the platform's folder for the game's name) is user://. The packages of the game and the player's mods are found and solved, their definitions loaded, and their scripts run in a world, as describes. A mod that fails is logged and left out; a base package that fails is an error of the game ().

    public static ScriptSession StartGame(string folder, string? userFolder, bool watch = false, bool realAudio = false, bool realSteam = false, bool runScripts = true, string? scene = null)

    Parameters¶

    folder string

    userFolder string?

    watch bool

    realAudio bool

    realSteam bool

    runScripts bool

    False makes everything a game has (the world, the file system, the models, physics, audio, the UI) without running the packages' scripts: what an editor edits before Play.

    scene string?

    Scene text () loaded into the world before the scripts run: what Play starts from.

    ScriptSession
