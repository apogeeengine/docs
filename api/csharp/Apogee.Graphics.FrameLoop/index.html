    Class FrameLoop¶

    Namespace: Apogee.Graphics
    Assembly: Apogee.Graphics.dll

    Keeps frames in flight (two by default): each has its own command buffer, upload arena and timer queries, and waits only for the frame that used its slot two frames ago. Without a swapchain it runs headless: the same frames with no window image, for screenshots, tests and servers. Made by .
