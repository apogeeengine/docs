    Class InputActionMap¶

    Namespace: Apogee.Input
    Assembly: Apogee.Input.dll

    Every action the player can bind, where each works (its contexts) and what it is bound to. Contexts are names the game chooses (world, on_foot, vehicle, menu); situations say which are active together, so two actions that can never be active at once may share an input. A turns the player's input into these actions.

    public sealed class InputActionMap : EngineObject
