    Class LuauVm¶

    Namespace: Apogee.Scripting
    Assembly: Apogee.Scripting.dll

    One Luau VM for the game and its mods. Every script runs in a thread of its own with its own globals over the read-only ones (luaL_sandbox), and belongs to a : the owner's memory category counts what it allocates, and its time budget limits each call. Not thread safe: use it from the thread that made it.

    ReloadModule(string)¶

    Runs a loaded module again from its file and updates it where it is: the module's table that every script that required it holds gets the new fields (and loses the ones the new code does not have), so they see the new functions without being reloaded themselves. What the module registered when it first loaded (functions that draw, signal connections, systems, defs.on_change listeners) is taken back and registered again by the new run. If the new code fails (a syntax error, a runtime error, a timeout) nothing changes: the old module and its registrations stay. A module may have a function on_reload(new, old), called before the update, to take state from the old table. A function a script copied into a local (local f = module.f) stays the old one; a module that returns something other than a table is replaced in the cache only.

    public ModuleReload ReloadModule(string path)
