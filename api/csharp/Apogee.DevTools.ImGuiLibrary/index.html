    Class ImGuiLibrary¶

    Namespace: Apogee.DevTools
    Assembly: Apogee.DevTools.dll

    Dear ImGui for Luau scripts, as the global table imgui: snake_case functions over the same calls the dev tools use. A widget returns changed, value; a window or tree that can be open returns whether it is; every begin has its end (ImGui recovers from a script that forgets, at the end of the frame). With no frame open every call does nothing and returns what it was given, so tool code can stay in a shipped game. Ids are the labels, with ImGui's ## and ### conventions.

    [ScriptLibrary("imgui")]
public static class ImGuiLibrary
