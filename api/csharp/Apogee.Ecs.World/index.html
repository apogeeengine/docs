    Class World¶

    Namespace: Apogee.Ecs
    Assembly: Apogee.Ecs.dll

    A Flecs world: entities, components, queries and systems. Components are the unmanaged structs marked [Component] (reflected, so Flecs knows their fields too) or ones a script defined at run time. Not thread safe: use it from one thread.

    public sealed class World : EngineObject, IDisposable
